# Religions-LernHTML

Fachprofil und künftige religionsspezifische Module für interaktive LernHTMLs.
Dieses Repository enthält bewusst nicht noch einmal die gemeinsame technische
Laufzeit.

## Abhängigkeit

Manifest, Rollen-Build, Klassenraum-/Beamerkern, Lehrerplattform, allgemeiner
LernHTML-Skill und Prüftools werden im öffentlichen Repository
[`markuspillermusic-hash/Lern-THML`](https://github.com/markuspillermusic-hash/Lern-THML)
versioniert. Die freigegebene Version steht in `core-dependency.json`.

Der Religions-Skill ergänzt dazu insbesondere:

- LehrplanPLUS Bayern und gA/eA-Differenzierung;
- philosophische und theologische Originaltextarbeit;
- didaktische Sinnoffenheit und Perspektivenvergleich;
- Kolloquiums- und schriftliches Abiturtraining;
- fachbezogene Quellen-, Medien- und Qualitätsprüfung.

## Neue Module

1. Modulstarter aus der festgelegten Kernversion kopieren.
2. Fachinhalt und Lehrplanbezug mit `skills/religion-lernpfad` entwickeln.
3. Modulmanifest, Rechteinventar und serverseitige Feedback-Registry pflegen.
4. Rollen-Build und alle automatischen Gates ausführen.
5. Vor Veröffentlichung echten Lehrer-/Schüler-/Beamer-Test durchführen.

Interne Materialsammlungen, private Screenshots, Raumdaten, Secrets und
urheberrechtlich ungeklärte Originaltexte gehören nicht in dieses öffentliche
Repository.
